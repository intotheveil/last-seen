# Last Seen — play in your browser

**Play:** https://intotheveil.github.io/last-seen/

A folk-horror visual novel adapted from the novel *Last Seen* by A. Damon.
This repository holds only the compiled web build (Ren'Py 8.4.1). Source is private.

Content warning: ritual murder, body horror, self-harm, sexual violence (in text), the death of a child (never shown).
An optional Mature mode (18+, chosen at first launch, changeable in Preferences) shows the violence against
the adult characters on screen. Scenes involving children are never shown graphically, in any mode.
